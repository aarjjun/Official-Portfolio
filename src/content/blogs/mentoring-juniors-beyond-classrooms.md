The most valuable technical mentorship rarely happens in a lecture hall. It happens in the chaotic 48 hours of a hackathon, or during a late-night Discord call debugging a failing API route.

Throughout my time as a Student Representative and Hub Lead, my primary focus has always been creating a culture of peer-to-peer enablement. The traditional academic structure is rigid; it teaches theory, but it often fails to teach resilience. Mentoring juniors beyond the classroom is about filling that gap.

### Teaching Resilience

When a junior student approaches me with a bug, my instinct is never to just take their keyboard and fix it. Doing so solves the immediate problem but destroys the learning opportunity. 

Instead, mentoring is about asking the right questions:
- What does the error message say?
- What was the last thing you changed before it broke?
- Have you checked the network tab?

By forcing them to navigate the debugging process, you are building their technical resilience. You are teaching them that a crash is not a failure; it is simply a data point telling them what to fix next.

### Hackathons as Learning Environments

I have made it a point to pair experienced developers with newcomers during university hackathons. The high-pressure environment strips away academic formalities. Juniors learn how to prioritize features, how to use Git collaboratively without causing massive merge conflicts, and how to communicate technical architecture to non-technical judges.

More importantly, they learn that nobody has all the answers. They see seniors frantically reading documentation at 3 AM. It humanizes the development process and removes the imposter syndrome that holds so many talented students back.

### The Compounding Effect

Mentoring is not a one-way street. The effort you put into guiding a junior developer today compounds. Six months down the line, that same student is leading a workshop or mentoring the next incoming batch. 

True leadership isn't about how much code you can write; it's about how many coders you can build.
